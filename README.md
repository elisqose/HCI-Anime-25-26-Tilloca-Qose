  ## Requisiti
  Installare le dipendenze con: pip install -r requirements.txt

  ## Dataset
  I file CSV non sono tracciati da git per via delle dimensioni.
  
  Prima di eseguire i notebook, inserire i file nella cartella corretta:
  - `datasets/` → file CSV raw forniti dal corso

  I datasets puliti vengono generati e salvati in automatico nella seguente cartella dopo l'esecuzione di ogni notebook. 
  - `datasets_cleaned/` → file CSV puliti (prodotti dai notebook di cleaning)

  Le cartelle sono già presenti nel repository (vuote).

  ## Ordine di esecuzione
  
  1. Inserire i CSV nelle cartelle come indicato sopra
  2. Eseguire i notebook in `solution/exploration & cleaning/` in ordine (01 → 13)
  3. Eseguire i notebook in `solution/storytelling/`
